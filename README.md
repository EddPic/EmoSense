# Sistema de Detección de Emociones - EmoSense

EmoSense es una aplicación IoT desarrollada para el monitoreo y registro de la salud emocional utilizando visión artificial y sensores biométricos. El sistema captura imágenes mediante una cámara conectada a Raspberry Pi, detecta emociones faciales usando Google Cloud Vision y recopila datos de sensores como BPM y GSR a través de MQTT. Los resultados se presentan en una interfaz gráfica amigable y se generan reportes en PDF para cada sesión, facilitando el seguimiento y análisis del estado emocional de los usuarios.
